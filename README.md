# Boxun Henny Zhu
## Administrador de Sistemas e Infraestructuras en Red

Perfil técnico enfocado en la administración, despliegue y aseguramiento de infraestructuras de red y sistemas corporativos. Especializado en entornos Linux, gestión de dominios en Windows Server, seguridad perimetral y automatización de tareas.

---

### Competencias Técnicas

#### Administración de Sistemas Operativos
* **Linux / Unix:** Administración y mantenimiento de distribuciones Ubuntu Server y Pop!_OS. Gestión de procesos, automatización de tareas vía `crontab`, configuración de interfaces mediante Netplan y análisis de registros del sistema.
* **Windows Server:** Despliegue y administración de Active Directory (AD DS), diseño e implementación de Objetos de Directiva de Grupo (GPO) para el control centralizado de usuarios, almacenamiento y seguridad.

#### Redes, Conmutación y Seguridad Perimetral
* **Servicios de Red:** Configuración y mantenimiento de servidores DNS autoritativos mediante BIND9 (zonas directas e inversas), asignación dinámica de direcciones (DHCP) y resolución de nombres.
* **Seguridad y Monitorización:** Implementación de cortafuegos y filtrado de paquetes con `iptables`, detección de intrusiones mediante Suricata (IDS/IPS) y auditoría de redes con Nmap.
* **Virtualización y Conmutación:** Configuración de switches virtuales y segmentación de tráfico con Open vSwitch.
* **Acceso Remoto y Diagnóstico:** Administración remota segura mediante SSH, diagnóstico de conectividad con Telnet e inspección de tráfico de red.

#### Automatización, Servicios Web y Desarrollo
* **Scripting y Automatización:** Desarrollo de scripts orientados a la gestión del sistema y análisis de registros en Python utilizando programación orientada a objetos (POO).
* **Infraestructura Web:** Despliegue, configuración y securización de servidores web Apache.
* **Tecnologías Web:** Desarrollo de interfaces y herramientas internas con HTML5, CSS3 y JavaScript.

---

### Enfoque de Trabajo

* Implementación de arquitecturas de red seguras y escalables para entornos Pyme y corporativos.
* Aplicación de directivas de mínimos privilegios y hardening de sistemas operativos.
* Configuración de servicios de alta disponibilidad y gestión centralizada de recursos.
